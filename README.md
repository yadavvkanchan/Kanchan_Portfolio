# Kanchan Yadav — Dark Developer Portfolio

A responsive, dark, animated portfolio built with React, Vite, Framer Motion, and Lucide icons.

## Run locally
1. Install Node.js (18+ recommended).
2. Open this folder in VS Code / terminal.
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed in the terminal.

## Build
```bash
npm run build
npm run preview
```

## Deploy on Vercel
1. Upload the project to a GitHub repository.
2. In Vercel, import that repository.
3. Framework preset: **Vite**
4. Build command: `npm run build`
5. Output directory: `dist`
6. No environment variables are required.

## Customize
- Edit project descriptions/links in `src/App.jsx`.
- Contact details and social links are in the same file.
- All project previews are custom-built animated interface mockups so visitors can understand the projects without leaving the portfolio. The “Live demo” links open the deployed projects.
